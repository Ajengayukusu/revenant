## What was broken (root causes)

1. **`node-sass@4.13.0` cannot install on Node 24.** It ships no prebuilt
   binary for this Node runtime, so its install script falls back to
   compiling libsass with its bundled `node-gyp@3.8.0`, which fails at
   the configure step (`Can't find Python executable "python"` — it looks
   for `python2`/`python`; verbatim log in `before-install.log`).
   npm rolls the entire install back, so *nothing* in the project can
   run: no `node_modules/.bin/gulp`, no `dist/`. The npm registry itself
   marks this exact version deprecated: "Node Sass is no longer
   supported. Please use `sass` or `sass-embedded` instead."
2. **`gulp-sass@4.0.2`** is the wrapper built on node-sass; it has to move
   with it. Its successor line (5.x) takes the Sass compiler as an
   argument instead of bundling node-sass.

That is the whole failure. Every other old dependency in the tree still
installs and runs on Node 24 (warnings only) — verified by the after run.
